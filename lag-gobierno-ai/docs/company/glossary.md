# Glosario — Gobierno de AI en LAG

| Término | Definición |
|---------|-----------|
| Herramienta autorizada | Software de AI aprobado por el comité de gobierno |
| Herramienta retirada | Software que ya no debe usarse (con razón documentada) |
| Nivel de clasificación | Sensibilidad del dato: Pública, Interna, Confidencial, Restringida |
| DPA | Data Processing Agreement — acuerdo sobre tratamiento de datos |
| Comité de gobierno AI | Grupo que aprueba/retira herramientas y define políticas |
| Intake process | Proceso formal para solicitar evaluación de nueva herramienta AI |
| Catálogo | Listado vivo de herramientas con estado y nivel permitido |
| Semáforo de uso | Verde (usar), Amarillo (con restricciones), Rojo (no autorizada) |
| Track rápido | Evaluación de herramienta Nivel 1-2 en 48h (IT + Líder de Área) |
| Track normal | Evaluación Nivel 3 en 5 días (SOC + Líder + Legal opcional) |
| Track complejo | Evaluación Nivel 4 en 15 días (Comité de Gobernanza + presupuesto) |
| SOC | Security Operations Center — equipo de seguridad |
| BMAD | Business Methodology for AI Development |
| SDD | Specification Driven Development — specs gobiernan el código |
