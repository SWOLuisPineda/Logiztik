# Clasificación de Datos — LAG

## Niveles

| Nivel        | Descripción                 | Ejemplos reales LAG                                                                                  |
| ------------ | --------------------------- | ---------------------------------------------------------------------------------------------------- |
| Pública      | Sin restricciones de acceso | Normativas de mercado, contenido publicado, docs técnicas públicas, info de aerolíneas               |
| Interna      | Uso organizacional          | Briefs creativos, prompts para Magnific, políticas internas, datos operativos (guías, pesos, vuelos) |
| Confidencial | Acceso restringido          | CVs de candidatos, base de leads, reportes de cartera, presupuesto, flujos de caja, datos SAP        |
| Restringida  | Máxima protección           | Contratos con firma, información regulada (GDPR/Habeas Data), credenciales de sistemas               |
