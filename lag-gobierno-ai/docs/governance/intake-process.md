# Proceso de Intake de Herramientas AI — LAG

## Flujo
1. Solicitud en HelpIT (formulario)
2. Clasificación de datos por Ingeniería de Soporte
3. Determinación del nivel de complejidad (1–4)
4. Asignación al track según nivel
5. Revisión y aprobación por responsables del track
6. Evaluación con 5 criterios ponderados (100 pts)
7. Decisión: aprobado o rechazado
8. Si aprobado: incorporación al catálogo
9. Si rechazado: comunicar razón y proponer alternativa

## Tracks

| Track    | Nivel | Tiempo   | Responsables                                    |
| -------- | ----- | -------- | ----------------------------------------------- |
| Rápido   | 1–2   | 48 horas | IT + Líder de Área                              |
| Normal   | 3     | 5 días   | SOC + Líder + (Legal / Gestión proveedores)     |
| Complejo | 4     | 15 días  | Comité de Gobernanza AI + presupuesto + sponsor |

## Criterios de Evaluación (100 pts)

| Criterio                             | Puntaje |
| ------------------------------------ | ------- |
| Seguridad de datos (DPA y políticas) | 30      |
| Valor de negocio                     | 30      |
| Costo                                | 20      |
| Integración con stack (SSO, APIs)    | 15      |
| Soporte y madurez                    | 5       |

## Formulario HelpIT (campos)

| Campo                                | Obligatorio |
| ------------------------------------ | ----------- |
| Nombre del solicitante               | Sí          |
| Área                                 | Sí          |
| Herramienta solicitada + URL         | Sí          |
| Caso de uso (¿para qué?)             | Sí          |
| Tipo de datos a procesar (4 niveles) | Sí          |
| Cantidad de usuarios                 | Sí          |
| ¿Existe alternativa aprobada?        | Sí          |
| Beneficio estimado                   | Sí          |
| Costo estimado                       | No          |
| ¿Es urgente? ¿Por qué?               | No          |
